# django-cte-examples

Examples of how to write CTE with Django ORM.

Medium article: [Using Common Table Expressions in Django](https://medium.com/@petrica.leuca/b6348c61574c?source=friends_link&sk=f5dd869ef9f81a3aab50559b98714b54)

# Run project

Prerequisites:
- Python >= 3.13.0
- [uv](https://docs.astral.sh/uv/)

1. Run `make install`;
2. Run `make run`;
3. Go to http://127.0.0.1:8000/admin/ and login with admin, with the same password.

The summary is in `Employee reports`.
